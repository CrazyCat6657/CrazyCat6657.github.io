钟声从地下深处传来。
带上武器，去看看回廊尽头还藏着什么。
· 找到下行阶梯，继续探索更深处的回廊。
· 战斗房进入即封锁，清空全部敌人才会开门；房间名旁边会显示剩余敌人数。
· 闪避期间无敌，可以穿过弹幕；左上角显示剩余次数与回充进度。
· 靠近桌子后使用交互键，可以翻倒它作为掩体。柱子和掩体也能挡住子弹。
· 铁壁卫兵 / 守界棱卫的盾牌可以打崩：持续正面输出会破盾并造成硬直；爆炸伤害直接无视盾牌。
· 橙色方块是风险宝库（可选精英房，高额奖励）；发光秘门后是隐藏房。
· 武器与遗物之间可能触发协同，可以在本局构筑中查看。

启 动 方 式 不 正 确

本游戏使用 ES Module 加载，需要通过本地服务器打开，
直接双击 index.html（file:// 协议）会被浏览器安全策略拦截。
正确做法：双击游戏目录里的启动脚本 —— 项目主目录是 启动稳定版.bat，独立电脑包是 START_GAME.cmd。
也可以在该目录执行 node tools/launch.mjs（独立电脑包用 node serve.mjs），再访问提示的地址。
